# Session 交接模板

较长任务或需要跨会话接续时，将本模板复制到 `docs/sessions/<日期>-<任务>.md`。写实际状态，不预填“全部通过”。不要记录凭据或复制整段运行日志。

## 目标与范围

- 用户目标及已经授权的操作：
- 工作树路径、分支、开始时的基线提交：
- 本 session 负责的文件/模块，已知重叠文件及协调情况：
- 不在本次范围的相关问题：

## 预期与复现

- 原有机制、已确认定制和本次期望行为：
- 实际使用的模组/整合包版本与哈希：
- 最小复现、正常对照、真实入口与根因证据：

## 已完成的改动

- 最终实现及兼容性/存档影响：
- 提交的日期、说明及提交 ID：
- 当前 HEAD、未提交文件及归属：

## 验证记录

| 检查 | 实际命令/操作 | 测试基线或产物哈希 | 结果与证据路径 |
| --- | --- | --- | --- |
| 针对性回归或旧版见证 | | | |
| 构建、JUnit、原生 GameTests | | | |
| 数据生成与资源核对 | | | |
| 客户端、输入/网络、整合验证 | | | |
| 保存、关闭、重启 | | | |
| 打包及下载核对 | | | |

未执行项写明“不适用”或“未执行”及理由。区分历史结果、本次执行、自动探针和人工观察；记录真实失败，不把方法级复现写成自然游玩必现。

## 待接续事项

- 下一步与仍需核实的假设：
- 阻碍、已知限制和需要用户提供的信息：
- 自己启动的进程、用途、PID 与身份核对方式：
- 自己创建的临时目录、可清理条件、需保留的证据/产物：
- 版本、发布清单、文档和提交是否同步完成：

结束时删除模板中无关的空行，保留其他 session 能直接接续所需的信息。
