# 物流美术 art-v2

2026-10-31，基线 `f0766da5`。本轮响应用户对反向汇入、密集坡道、粗糙带面和偏暗边框的反馈。资源未接入物流功能。

- 网页支带绕 Y 轴由 +90° 改为 -90°。原箭头朝远离主带的负 X 方向，修正后朝正 X 汇入。主干仍向北输出。
- 坡道由 48 个台阶元素改成 3 个连续旋转元素，分别为带面和两侧边框。上坡顶面两端在方块局部坐标的 y/z 为 2/16 和 18/0，与下层和上层平带顶面衔接。下坡对应反向。
- 带面由 16×16 改为 32×32，每帧细纹降低对比；箭头比例缩小，汇入处增加侧向箭头。边框和分拣器保持 16px。
- 三档边框均提亮，铜色增加橙铜色和浅色高光；名称及配方无变化。
