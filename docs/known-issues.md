# 已知问题与验证边界

## 暮色森林独立服务器启动

local5 的 `RegistrationEvents.setupPackets` 存在客户端 `ClientLevel` 类引用，在此前独立专服验证中可复现。加装或移除茶工艺均能触发，因此不能归因于茶工艺。当前完整八模组交付按客户端与集成服务器使用，不宣称支持独立专服。本次只整理仓库，没有顺手修改网络注册。

## 暮色刷怪笼处理器

此前审计定位到 `SpawnerProcessor` 对缺失属性列表、已有 SpawnData 以及旧 scale 属性名称的条件分支风险。尚未证明当前随包模板在自然生成中必定触发，也未在 local5 交付中列为完成修复。后续修改前应重新复现，并分别检查空实体、已有实体、普通蜘蛛和已有缩放属性。

## IC2 分拣器版本与新旧语义

2026-11-21 的 `local.17-directional.1` 源码将 D 改为六面可选的主动输入路径，输入和其余五面输出均需设置白名单，没有默认兜底。它取代此前“固定上方输入”的开发规则；原 local35 和更早交付 JAR 不会自动获得新规则。当前本地仓库缺少 local35 完整源码，不得用本次 local17 源码 JAR 覆盖 local35 的其他功能。

新传输按 NeoForge 库存接口和真实接触面执行，能支持原版箱子/双箱、木桶及提供兼容接口的模组存储；不承诺任意专用容器。输入白名单数量不构成取料批量，输出白名单数量是启动一批的门槛；批次开始后逐刻发送，目标拒收时保留物品并等待。
