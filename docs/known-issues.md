# 已知问题与验证边界

## 暮色森林独立服务器启动

local5 的 `RegistrationEvents.setupPackets` 存在客户端 `ClientLevel` 类引用，在此前独立专服验证中可复现。加装或移除茶工艺均能触发，因此不能归因于茶工艺。当前完整八模组交付按客户端与集成服务器使用，不宣称支持独立专服。本次只整理仓库，没有顺手修改网络注册。

## 暮色刷怪笼处理器

此前审计定位到 `SpawnerProcessor` 对缺失属性列表、已有 SpawnData 以及旧 scale 属性名称的条件分支风险。尚未证明当前随包模板在自然生成中必定触发，也未在 local5 交付中列为完成修复。后续修改前应重新复现，并分别检查空实体、已有实体、普通蜘蛛和已有缩放属性。

## IC2 分拣器的输入与目标容器

本地 `local.17-topinput.1` 源码版本及经过实际 JAR 验证的 `local.21-topinput.1` 兼容修补版新增正上方原版单箱/双箱的主动取料，上方作为输入口，不再输出；原 local17/local21 交付包不会自动获得该能力。仍不抽取其他方向的箱子或吸取掉落物，漏斗或主动输出管道也可供料。过滤数量仍表示整批发送量，未凑齐时等待。现有邻接输出适配器不承诺支持任意模组的专用存储，例如茶工艺大容量茶盒。

初始维护基线已有 IC2 577 项原生 GameTests、22 项分拣器针对性测试及八模组客户端自动验证；暮色 local5 历史记录为自身 85 项测试与独立验证 69 项。它们是此前交付的历史证据，不等于每次后续提交都已重新执行这些检查。
