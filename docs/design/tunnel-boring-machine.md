# 玩家驾驶盾构机初步策划

日期：2026-10-31。状态：讨论提案，尚未实现。

初稿基线为 `5e9b16c9`，定位修订基线为 `e807ecc4`，IC2 源码版本为 `26.3.0-local.17`。未核对玩家实际使用的 JAR，本文不代表运行验收。初稿时工作区已有物流模组及相关文档的未提交内容，不属于本策划范围；定位修订开始时工作区干净。

用户提出小、中、大三档机型，可更换 IC2 电池和钻头，由玩家操作进行地下横向采矿。后续明确组合性是核心，希望加入吸水、冷凝升级模块，以及消耗自备建材铺设管壁的搭建模式，能够组合完成海底隧道。用户更偏好缺口补壁的采矿用途。尺寸、配方、耗电、模块槽数量和默认模式仍是待确认建议。

## 核心玩法

玩家组装机身、装入电池与钻头、坐进驾驶位，按住掘进键开出水平隧道。挖到的东西进入机载货仓，玩家负责选路线、换电和卸货。松开按键、离开驾驶位或掉线后停机，重新进入世界也保持停机。

组合性是主要玩法：基础机提供掘进与收料，玩家按路线搭配流体处理、管壁施工、能源和储物模块。模块组合应带来新的通行能力，例如穿过水域，而不只是叠加速度数值。自动执行局部施工步骤仍需玩家驾驶，不增加无人运行或自动寻路。

建议先做固定结构的模块组装：底盘、掘进头、能源舱和货仓在装配界面组合，装好的模块体现在模型上。每台机器作为一个整体移动，不允许任意方块拼成移动建筑。这样仍有组装和升级的乐趣，碰撞与存档范围也较明确。

## 与采矿镭射枪的定位差异

用户进一步指出，小型盾构机必须在实际使用中有独立价值，不能只是更笨重的采矿镭射枪。动力来源可以参与差异化，但增加电量本身不足以成立。以下是修订建议，尚未确认。

当前镭射枪已有水平、3×3、散射等模式。仅靠横向开挖或更大断面无法建立定位。建议让镭射枪继续适合随身探险、零散开采与临时开洞，让盾构机专长于长距离矿道施工与集中收料。

| 玩家任务 | 镭射枪现有特点 | 盾构机应提供的价值 |
| --- | --- | --- |
| 洞穴里挖几处矿、临时换方向 | 随身使用，可改变射击方向 | 接受部署和转向较慢，不争夺这个用途 |
| 连续开出指定断面的长矿道 | 多束射线分别消耗穿透能力，结果受沿途方块影响 | 一层挖齐后再推进，减少补挖和校正路线 |
| 收集大量开挖产物 | 普通破坏路径把掉落生成在世界中 | 所有应有掉落直接入货仓，货仓满则停机，不占用玩家随身背包 |
| 保留矿物收益 | 普通破坏路径以时运参数 0 求掉落，再应用默认 0.9 的掉落概率；事件可修改 | 按钻头正常掉落规则结算，不额外随机销毁产物，后期支持时运或精准采集 |
| 持续施工补给 | 电能工具，可补充电量 | 可选车载燃料发电与停车接电，配合更大的集中货仓 |

上述镭射枪行为来自当前源码阅读，不代表本轮实测，也不概括爆炸、熔炼等所有模式。无需削弱镭射枪来给新机器让位。铱钻头的收益只能算后期加成，小型机在普通钻头阶段就应凭连续作业、直接收料和较少整理获得用途。

动力建议区分电池与动力模块。电池负责储能和短时供电；可选燃料发电模块消耗玩家装入的燃料，延长持续作业时间，输出不足时仍会耗尽电池。停车接电用于工地补给。车载发电模块可参考 IC2 发电机制制作专用组件，不承诺任意现有发电机方块都能搬上车运行。行驶中拖接电缆涉及移动电网连接，首版不建议采用。

初步可设“电池 + 大货仓”与“电池 + 发电模块 + 较小货仓”两种配置，让玩家选择更少卸货还是更少回程充电。燃料发电需单独计成本，不自动意味着更高能效；不默认燃烧刚挖出的煤炭，以免消耗玩家想保留的产物。槽位和容量均待定。

照明仍可作为后续可选模块，按间距在已挖隧道的合法位置放灯。用户新提出的流体处理和管壁施工已成为目标玩法，替代初稿“一律遇液体或空洞停机”的限制；只有模块、材料、供电或施工条件不足时才必须停机。具体组合规则见下文。

小型机的可玩验收应与镭射枪比较完整任务。例如完成一条 3×3、长 100 格的矿道，分别记录部署、挖掘、补挖、收料、补电与卸货所需时间，另测短距离临时开洞。100 格只是测试场景，不是强行规定的优势分界线。应让玩家在长矿道场景中明显少操作、少整理，并有可接受的总耗时和成本；若只是按住键更久，仍需反复下车收拾，就应调整设计，而非单纯提高大型机数值。

## 规格与模块

| 机型 | 建议内部净空，宽 × 高 | 用途与代价 |
| --- | --- | --- |
| 小型 | 3 × 3 | 长支线矿道与集中收料，基础钻头阶段就应有用途 |
| 中型 | 5 × 5 | 常用主矿道，货仓更大，供电需求更高 |
| 大型 | 7 × 7 | 大规模掘进和地下工程，昂贵且更难掉头 |

尺寸建议表示施工后的内部净空，机身应略小并留出驾驶员安全下车空间。管壁位于净空外侧，不把 3×3 矿道铺成 1×1。大机型提升每层覆盖量，不默认同时提升前进速度。同样的供电下，挖更多方块应更慢。

能源舱复用 IC2 可充电电池、进阶电池、能量水晶和兰波顿水晶。容量决定续航，供电能力限制持续掘进速度，底盘和钻头共同决定速度上限。电池输出不足就降速或等待充能。更换模块必须停机，原物品及剩余电量保留。

建议把用户所说的“效率”先定义为单位时间开挖量。高级电池能让机器跑得更快、更久，但不直接降低每块矿石的耗电，避免一次升级同时获得所有收益。每块耗电、供电预算与缓冲容量待原型测试确定，不能直接把现有电池传输参数当作机器的 EU/t。

钻头建议直接使用现有采矿钻头、钻石钻头和铱钻头作为模块。普通钻头负责入门，钻石钻头提升开采能力，铱钻头提供高阶开采和时运收益。装入的钻头必须真正参与掉落计算，不能只让界面显示时运。时运只影响原本支持它的掉落。

当前铱钻头源码已有时运 III 与精准采集切换。建议机器尊重装入钻头的当前模式，停机后取下切换，不叠加两种效果。能源舱统一支付机器运行与钻头开采的总耗电，具体接入时避免钻头与机身重复扣电。

## 环境模块与管壁搭建

本节组合需求来自用户最新讨论，修订基线为 `bec4c2a1`。以下具体规则是策划建议，没有修改游戏代码。

| 模块 | 建议材料方向 | 能力与边界 |
| --- | --- | --- |
| 吸水模块 | 海绵与机械部件 | 处理本次施工范围内的水源和流水，优先用于密闭后的内部排水；不向整片海域递归吸水 |
| 冷凝模块 | 蓝冰与机械部件 | 将施工范围内的岩浆冷却为可处理的固体，再由钻头开采；不能直接凭空删除岩浆并额外发放产物 |
| 管壁施工模块 | 机械部件与建材仓 | 消耗玩家提供的建材，在净空外侧补墙、顶和底板，与流体模块配合封闭水域或岩浆区域 |

海绵、蓝冰先作为模块配方方向，不预先规定每处理一格就消耗一块。运行耗电、额外耗材和冷却产物待定。冷凝后的方块若超出所装钻头能力，应停机提示；不能靠冷凝模块跳过钻头等级。吸水或冷凝单独安装不能保证穿越开放海洋或岩浆海，外部流体隔离还需要施工模块。

建议施工设置有三档，安装模块后默认选择“缺口补壁”：

- 关闭：不消耗建材铺壁；遇到无法安全隔离的水域或空洞就停机。
- 缺口补壁：保留完好的天然围岩，只补净空外侧的空气、流体和不能可靠封闭的部位。用于采矿，材料消耗低；穿过开放水域时会自然补成完整一圈。
- 全断面衬砌：每层外圈都使用指定建材，必要时开挖并回收原围岩。用于统一外观的永久隧道，增加耗材、开挖量与耗电。

“缺口”不能仅判断是不是空气。现有边界能否挡水、是否含水、会不会坠落都要检查，最终兼容范围由实现与测试确定。首版建材建议限制为稳定、完整且可密封的方块；玻璃可作为可选候选，半砖、楼梯、沙砾等先不承诺兼容。替换边界方块也须检查破坏权限、正确收集掉落，不覆盖箱子、机器、保护方块或占位实体。

建议管壁厚一格。以 3×3 净空为例，全包围外轮廓为 5×5，每延伸一格的方形外圈共 16 个位置。缺口模式只消耗实际新补位置的材料，完整岩层中可以为零；全衬砌需将外圈处理成指定材料，已有符合要求的方块不重复扣料。界面预览下一层的施工范围、预计建材数和不足原因。

### 海底掘进的组合顺序

典型配置为“钻头 + 吸水模块 + 管壁施工模块 + 密封建材”。玩家进入水域时持续驾驶，机器按层完成以下工作：

1. 检查本层及封闭所需位置已加载，模块、电量、建材和货仓容量满足本步要求。
2. 隔离外部流体，在前端施工区域维持封闭，并补好本层周围的管壁。
3. 清除隔离区域内的水与障碍，确认内部可通行后推进，留下干燥隧道。

只补侧壁、顶和底还不够，水可以从正在掘进的前端进入。需要设计实际阻挡流体的盾壳或临时封闭结构，不能假设机器实体模型天然挡水。这是需要原型验证的关键实现点，本文不把施工顺序当作已验证算法。初次进入水域时还要检查后方已有隧道连通处，不能从后方倒灌。

缺材料、缺电、玩家下车或退出游戏时，机器应停在能够维持封闭的状态，不继续破坏边界。海中倒车或收回机器前，必须封好暴露端面，或阻止操作并提示补料。不能简单移除临时盾壳留下水口。保存重启要保留未完成施工、临时封闭和物料状态，避免复制建材或丢失产物。

小型机必须能同时装下实现这套基本组合所需的模块。中大型可以增加货仓、动力与拓展余量，不能把“小型模块槽不够，无法同时排水与补壁”作为强制升级理由。具体槽位数量与兼容限制待定。

## 玩家如何操作

1. 放置已组装机器，选择东、西、南、北朝向，装电池与钻头。
2. 坐进驾驶位，界面显示电量、货仓余量、钻头模式与停机原因。
3. 选择施工模式、装入建材并按住掘进键，机器完成前方一层的开挖、必要封闭与流体处理后前进一格。动画可以平滑，逻辑按格处理。
4. 支持沿已清空的隧道倒车。转向只能停车后进行，并检查整个转向空间；首版不做自由转弯、斜向或上下掘进。
5. 停车卸货和换模块。首版通过货仓界面卸货，自动物流连接后续再评估。

遇到水、岩浆或空洞时按所装模块与施工模式处理，能力不足则停机。施工只处理本机断面及必要外圈，不填平整个洞穴或排干周围海域。不可破坏方块、容器、机器方块及占位生物仍会阻止施工。不增加自动追矿。

缺电或货仓不足时停止下一次破坏，已经挖开的方块保持现状，不强求整层一次完成。不得丢弃装不下的掉落，也不能重复随机计算时运来挑选结果。具体的暂存与保存方案在实现阶段确定。

## 实现难度判断

玩家驾驶可以省掉无人作业调度、自动寻路和机器主动维持区块加载，范围确实比远程全自动矿机小。机器只操作当前已加载且可运行的区块，前方尚未就绪就等待，不替玩家强制加载。

这仍然是一个有一定复杂度的新功能。大机身可能同时跨多个区块，移动与驾驶员碰撞、多人控制权限、开采掉落、模块电量和保存重载都要单独验证。玩家在场不会自动解决这些问题。所有开采与扣电由服务端决定，并遵守玩家的破坏权限和暮色进度保护。

开发建议先用小型机验证驾驶、直行与倒车、电池更换、钻头效果、货仓停机、跨区块等待和保存重启，再验证模块组合。只有基础掘进的技术原型不代表核心玩法已完成。组合验收应包含从岩层进入水域、横穿水域后重回岩层，检查管壁消耗、内部净空、反复进水、缺电缺料停机、海中退出驾驶及保存重启。冷凝模块另测岩浆源与流动岩浆、钻头等级不足、建材适用性和冷却产物结算。通过后再扩展中大型；速度、耗电、货仓大小和制作成本在实际试玩后定值。
