# 累计修改与版本

## 分拣机上方主动取料，2026-11-01

基于本仓库 local17 源码新增 `local.17-topinput.1` 开发版本。分拣机在有至少 20 EU 时每刻从正上方贴合的原版单箱或双箱取 1 个物品，缓冲区无容量时保留源物品，再按其余五面的过滤与默认出口规则输出。上方固定为输入，旧默认上方出口迁移为下方，旧上方过滤规则保留在存档中但不再生效；东方过滤规则无需重建。取料不额外扣电，成功输出仍为 20 EU/物品。界面上方不再提供输出切换及虚拟过滤槽。

本仓库源码基线仍为 local17，未虚构已导入 local18–21 完整源码。另提供受限的 `local.21-topinput.1` 兼容修补包：核对原 local21 分拣相关 5 个类与仓库旧逻辑的归一化字节码一致后，使用完整源码编译的变更覆盖必要条目，另 8582 个条目逐字节保留。实际修补 JAR 的 637 项原生 GameTests 和两次真实保存重启通过；未安装到房主或玩家实例。构建和验证边界见 [本轮记录](verification/sorting-top-input/README.md)。

## 物流美术修订 art-v2，2026-10-31

修复评审页支带朝外的旋转方向，改为向主带汇入；坡道由密集台阶改成连续斜面；带面提升到 32px 并采用细窄低对比纹理；提亮三档边框，铜色改为更浅的橙铜色。同步实际资源和网页显示，未实现运输逻辑。见 [本轮验证](verification/logistics-art-v2/README.md)。

## 物流资源首版，2026-10-31

新增 `mods/logistics` 的低速、中速、高速传送带与分拣器资源。名称及 ID 与材料、配方分离。包含像素贴图、带面材质动画、直线／转弯／汇入／升降模型、分拣器完整模型与活动部件、三维物品图标定义、中英文本，以及直接读取实际资源的交互评审页。资源生成、静态校验和隔离展示工具可复用。

这是美术评审产物，没有实现传送、库存、配方、Java 注册或正式模组 JAR。单格与悬空规则是后续实现约束，网页动画不是游戏逻辑验收。说明与验证边界见 [物流资源说明](../mods/logistics/README.md) 和 [本轮验证](verification/logistics-art-v1/README.md)。IC2、暮色版本及已交付八模组清单未变更。
