## 核对

从两个原 Git 仓库的 HEAD 建立上游快照提交，再分别保存 IC2、暮色森林当前累计工作树。没有把临时目录当作子模块，没有链接到旧源码，也没有移动或清理原仓库。

导入时 IC2 共 7,669 个文件，暮色森林共 9,829 个文件。除下述四处维护调整外，17,494 个文件与导入前逐字节一致：

- IC2 `gradle.properties` 中版本号由遗留的 local10 对齐至 local17。
- 暮色森林 `gradle.properties` 中版本号由 4.9 对齐至 4.9-local.5。
- 移除 IC2 `.gitignore` 中过宽的 wrapper JAR 忽略项，确保源码仓库可从 wrapper 启动。
- IC2 GameTest 默认选择器改为 `ic2:*`，避免只跑原版一项自检。统一入口额外核对 XML 中确实存在 IC2 测试。

另将独立验证工程中的旧目录引用改成 `../../mods/twilightforest`，并在独立测试前实际执行 `runClientData`，生成其需要的对照数据。迁移工具保存在只供阅读的档案目录，当前构建工具不使用旧绝对路径。

最新可用交付记录中 56 个 IC2 源码哈希与当前源码相符。完整历史 ZIP 与其中八个 JAR 的哈希及 JAR 完整性已核对。仓库布局、版本清单、10,559 个 JSON 的语法检查、Python 编译和 shell 语法检查通过。

逐文件清单和结果见 `provenance/imported-files.json`、`import-verification.json`、`release-source-crosscheck.json`。历史报告与新目录验证分别记录，避免把过去通过的测试当成本次重新执行。
