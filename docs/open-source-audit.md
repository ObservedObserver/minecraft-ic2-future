# 公开仓库前的内容审查

审查日期：2026-10-31。目标是供朋友联机使用和维护，只检查仓库收纳范围、提交历史和公开时会暴露的信息，不扩展大众安装流程。

审查基线为 `main` 上的 2026-10-31 提交 `docs: propose player-operated modular tunnel boring machines`，提交 ID 为 `4875e840`。完整 ID 见[结构化结果](verification/open-source-audit/summary.json)的 `baseline_head`。

## 结论

TeaCraft 源码和 JAR 没有收进当前 Git，也没有出现在本地任何现存引用可达的历史提交中。JEI、Xaero 小地图、Xaero 世界地图、Inventory Profiles Next 和 libIPN 同样没有作为独立模组源码或成品 JAR 引入。当前收纳方式符合“维护自己修改的模组源码，其他游玩模组只记录版本与来源”的目标。

公开前值得处理的是个人信息，而不是删除 TeaCraft 源码。提交身份带有个人 QQ 邮箱，10 份历史记录包含本机用户目录。是否保留这些信息需要由仓库所有者决定。本次只记录事实，没有删除文件、改写历史、配置远端或公开仓库。

TeaCraft 字样出现在 9 个已有文件中，包括 [历史交付清单](../pack/mods.lock.json)、[来源与许可](../NOTICE.md)、[已知问题](known-issues.md)和 IC2 local17 测试记录。清单中的 `mods/tea-craft-…jar` 是文件名字符串，不是 Git 中存在的文件。删除这些记录会损失历史八模组包的核验信息，也不会让当前源码更干净。

## Git 历史与产物检查

- 当前索引包含 17,670 个文件。逐个检查全部 12 个历史提交的目录树，共 17,862 个不同历史路径。
- 本地分支、tag 和 Codex 辅助引用可达的提交集合相同，共 12 个提交。进一步读取了全部 19,809 个可达 blob，合计 62,077,007 字节，检查 TeaCraft 内容和归档文件特征。
- 当前及历史中的 `.jar` 路径只有三个工程的 `gradle/wrapper/gradle-wrapper.jar`。其中两个工程共用相同 blob，因此文件特征扫描只列出两个不同内容对象。这些 wrapper 是构建入口，应保留。
- 没有发现提交的整合包 ZIP、模组成品 JAR、编译 class、玩家世界、数据库、日志、运行依赖目录、嵌套 Git 仓库或子模块。
- 上游基线历史中确实存在后来删除的暮色数据生成 `.cache` 索引。这些是生成器记录，不是第三方模组源码，也没有必要为它们单独重写历史。
- `.git` 当前约 54 MiB。最大的历史 blob 是约 2.65 MB 的来源哈希清单，其后主要是概念图和暮色音乐资源，没有发现大体积交付包混入历史。
- 当前没有配置 Git 远端。以上结论覆盖本地引用可达历史，不包含不可达对象、外部旧任务目录或未检查的其他仓库。

本机 `.local/logistics-art` 中有隔离展示用的 Minecraft 客户端和依赖，物流目录也有生成的资源 ZIP。这些被 Git 忽略，不会随正常提交发布。它们属于其他进行中的工作，本次没有清理。
