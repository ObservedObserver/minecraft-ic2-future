# IC2 作物架踩踏与穿地修复 local15

适用 Minecraft 26.3、NeoForge 26.3.0.83、Java 25。以已交付 local14 为基线，保留硝石火药、蛤蛤粉来源、流体移动及此前所有修复。

## 已确认的原因

### 奔跑会触发旧的随机踩踏

`TileEntityCrop.onEntityCollision` 调用作物卡碰撞回调。默认回调对奔跑中的活体返回 true，随后执行约 1% 的随机判定和抗性判定，清空作物并直接把下方耕地写成泥土。因此这部分确实是代码自带的旧行为，不是操作错误。

另外，玩家跳落时，原版耕地的踩踏路径仍然会把作物架下方耕地变成泥土。本次取消 IC2 作物架下方的原生耕地踩踏事件，覆盖空架、杂交架和已种植的各类作物。

### 土块仍在但玩家掉下去

耕地碰撞高度是 15/16 格，普通泥土是 1 格。旧的随机踩踏直接替换方块，没有调用原版转换路径中的 `Block.pushEntitiesUp`。玩家脚原来在 15/16 高度，替换后处在新土块内部，后续移动会穿到土块下方。

旧版 local14 的负向复现记录为：土块仍然是 `minecraft:dirt`，玩家脚 Y 已低于该土块。对应测试 `sprintingOverWaterNeverDropsPlayerThroughExistingSoil`，见 `before-final.xml`。本次移除了作物接触触发的随机毁田路径。

### 杂草扩散把土块变成没有碰撞的草

`performWeedWork` 原先把旁边的泥土或耕地替换成 `SHORT_GRASS`，而不是实体 `GRASS_BLOCK`。在水上薄层农田中，新草没有合适的支撑还会变为空气，真实挖出一个洞。这与“土块仍在”的穿地是不同的第二条问题路径。

现改为保留实体草方块地面；若从低一截的耕地转换，则先调用原版 `Block.pushEntitiesUp` 把站立实体顶到新增地面高度。上方有两格空间时正确放置高草上下两半；只有一格空间时放普通草，不覆盖上方已有方块。

### 普通掉落物没有直接踩坏判定，另有干涸退化遗漏

普通 `ItemEntity` 不满足作物卡的活体奔跑判定，也不满足原生耕地踩踏的活体条件。单独的掉落物碰撞、落地测试在旧版和新版都通过，没有确认“掉落物本身直接破坏”的因果关系。

但本版确实漏给 68 种 IC2 作物方块添加原版 `minecraft:maintains_farmland` 标签，导致干燥耕地即使上面有作物架，也会随机退化成泥土，随后作物架因失去合法土壤而消失。这可能与物品落地同时发生，被观察为掉落物触发。本次补齐全部 68 种，包括空架、杂交架、杂草和苍白树苗等。

耕地正下方的水不等于原版有效灌溉范围。本次保留原版水分规则；添加标签使有作物架的干燥耕地不再因此退化，不代表水分被强制补满。

## 修改范围

- `TileEntityCrop.java`：保留作物专属接触效果，取消随机毁作物、毁耕地；修复杂草地面及高草放置；抬高地面时先推离实体。
- `EventHandlerForge.java`：只保护 IC2 作物架下方耕地，不改变普通耕地和原版小麦的踩踏规则，也不取消摔落伤害。
- `data/minecraft/tags/block/maintains_farmland.json`：追加全部 68 种 IC2 作物方块，`replace=false`，保留原版和其他数据包的标签成员。
- 新增 `CropGroundGameTests` 并注册。专门作物的接触效果仍执行，例如毒花接触中毒与阶段变化。

不修改地形生成，不自动补回此前已丢失的土块或作物。已损坏处需要补土、重新锄地或补放作物架。

## 验证

- 最终 JAR 的 17 项针对性原生 GameTest 全部通过，见 `targeted-final.xml`。
- 将相同最终测试覆盖到旧生产 local14 JAR，仅覆盖测试类和测试注册类，不覆盖生产代码及资源，17 项中 12 项按预期失败，见 `before-final.xml`。掉落物、普通耕地、小麦踩踏、裸地干涸、毒花效果等对照在旧版也通过。
- 最终完整套件 550 项全部通过，见 `all-verified.xml`。最初全量测试中高级采矿机和火把花收割两项出现失败，两项独立运行均通过。新测试移入独立 `crop_ground` 批次后重新完成完整套件；不改动这两个旧测试或其生产实现。首次报告和独立报告保留，未把首次失败记成通过。
- 实际七模组客户端与集成服务器自动验证：空架、已种小麦、杂交架、普通泥土、杂草转换后的地面，共 5 个水上薄层农田场景。每个场景步行/奔跑、四个方向，共 96 次实际 `LocalPlayer.travel`，总计 480 次；检查脚高度和实际包围盒不与实体方块相交。
- 杂草转换现场，真实服务器玩家脚 Y 从 5.9375 被顶至 6.0。此场景周围仍有较低的耕地，因此跨过边界时允许正常下降 1/16 格，同时断言不进入任何实体方块。初次客户端测试误把这一下正常落差当成穿地，已修正测试夹具的判断并保留失败记录，生产修复代码没有因此放宽。
- 客户端验证采用自动物理检查，未进行人工游玩。临时验证模组不随包交付。最终客户端使用的 JAR 与交付 JAR 哈希一致。
- 所有未覆盖 JAR 条目与 local14 逐字节相同；增量补丁对修改前快照的 `git apply --check` 通过。

## 构建、安装与证据

本次通过保留的 Java 25 依赖增量编译，避免重建大型 Gradle 缓存。`build-record.json` 记录基线、源码、覆盖条目与最终 JAR 哈希。`验证结果.json` 汇总测试和客户端证据，`client-validation.json` 保留每个场景的脚高度、位移和地面抬高数据。

退出游戏后移除旧 IC2 JAR，再放入 local15，保留自己的世界与配置。同一模组不要同时保留多个版本。整合包仍含七个模组，其余六个 JAR 与 local14 相同；许可、来源、之前的修复资料随包保留。
