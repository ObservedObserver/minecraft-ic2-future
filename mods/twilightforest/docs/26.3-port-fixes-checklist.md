# Minecraft 26.3 问题与修复 checklist

更新时间：2026-10-25。基线为 TF local.3 + IC2R local.6 + JEI 31.16.0.90。四项代码修复进入 TF local.4 候选，IC2 与 JEI 保持原文件。

本表把代码修复、自动验证、真实画面和扩展验收分别记录。勾选只表示该行内容已经完成，不等于全部玩法或 Windows 真机验收。保留未完成项，不拿已有日志替代本次画面观察。

## WG-01 结构地形密度遗漏，优先级高

症状为自然生成矿山缺少山体，只留下独立放置的矿石、刷怪笼等。21 个结构配置中 16 个依赖受影响的密度或地形适应路径。三种矿山都遗漏同一贡献，外观严重程度取决于原有地形。

修复位置为 `TFDimensionGenerator.makeNoiseSettings`、`twilight_noise_gen.json`、`skylight_noise_gen.json`。约束是 final_density 在最外层恰好叠加一次 beardifier，chunk_surface_level 仍使用基础地形；不能只修矿石放置或仅测试采样函数。

- [x] 修改数据生成源码及普通暮色、Skylight 两份资源。
- [x] 运行 runClientData，并核对随包文件与输出字节一致。
- [x] 验证真实 add codec、实际 hook 目标和候选包资源。
- [x] 普通暮色新生成小、中、大矿山抽查山体、洞顶、空腔和矿石。
- [x] 抽查九头蛇巢穴、雪怪洞穴的地形和入口。

- [ ] 补足迷宫入口与周边地面的清晰抽查，目前画面受树木和天气遮挡。

旧异常区块不会自动补回山体。没有删除或重建个人存档区块；已有正常地形不会因本修复被主动擦除。

## WG-02 冠层和冰川覆盖入口失效，优先级高

旧目标 `ChunkStatusTasks.generateSurface` 在 26.3 已不存在。受影响的是黑暗森林额外连续冠层和冰川覆盖主体，独立树木、建筑并不因此全部停止生成。

修复位置为 `ChunkStatusTaskTransformer` 和 `WorldgenHooks.chunkBlanketing`。新目标为 `NoiseBasedChunkGenerator.generateCarvers`。覆盖放在该方法开头，维持表面生成之后、雕刻器之前、后续装饰之前的顺序。

- [x] 更新精确目标、描述符及 chunk/region 参数槽位。
- [x] 检查每区块执行一次，拒绝重复注入或目标失配。
- [x] 实际 26.3 类文件回归验证调用次序与堆栈。
- [x] 审核完整处理链的并发访问，写入仅限中心区块，邻区只读取生物群系。
- [x] 合法 null region 路径跳过覆盖并记录一次 debug 信息。
- [x] 新生成普通暮色区域实际观察连续冠层和高厚冰川主体、冰顶。
- [x] 两个独立正式服务端各生成 512 区块；对应覆盖层材料位置未发现差异。
- [ ] 扩展检查 carver 洞口贯穿冰川、冠层的外观。

完整区块另有草木等差异，不能把材料比对写成整套世界生成完全确定。非 noise 的第三方生成器和旧区块升级路径尚未实际覆盖。

## FX-01 皇帝布帛盔甲可见度签名失配，优先级中

修复位置为 `ArmorVisibilityRenderingTransformer`。26.3 的 `getVisibilityPercent` 增加了 ServerLevel 参数。折扣应接在 getArmorCoverPercentage 返回之后、原版最小可见度限制之前。

- [x] 更新完整签名，摆脱旧局部变量槽位假设。
- [x] 精确匹配唯一的护甲覆盖率调用，失配时明确失败。
- [x] 验证真实类文件堆栈及 public static hook 链接。
- [x] 测试 0 至 4 件布帛组件的折扣和既有 ArmorUtil 行为。
- [ ] 扩展实机检查隐身条件下的怪物索敌距离。

## FX-02 无拘无束防残余弹跳入口失效，优先级中

## 修复和复核顺序

1. WG-01、WG-02 先修，避免在缺少结构地形的基础上继续调整装饰。
2. FX-01、FX-02 各按 26.3 当前方法语义修改，不仅替换方法名。
3. 执行 runClientData、build/shadowJar、独立验证工程 test。修改数据生成源码后必须先重跑 runClientData。
4. 审计实际 JAR 的 27 个目标、资源和哈希，再做本次真实游戏抽查。
5. Claude Opus 5.5 审查最终差异。发现确定缺陷则修复并复核，保存实际版本和模型证据。
6. 发布候选时带上未覆盖项与旧存档影响，不把待办项自动勾选。

详细证据见同目录的修复与验证说明、验证记录和 Claude 各轮评审文件。
